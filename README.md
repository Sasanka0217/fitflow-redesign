# FitFlow Redesign

FitFlow is a fitness application redesign proposed for the IT3060 Human Computer Interaction Lab Exercise 05.

## Technology Stack

- Frontend: Flutter
- Backend: NestJS
- AI Service: FastAPI
- Database: PostgreSQL
- Caching / Real-Time: Redis
- Authentication: AWS Cognito

## Project Structure

- frontend/ - Flutter application
- backend/ - NestJS backend services
- ai-service/ - FastAPI AI microservice
- docs/ - Project documentation
