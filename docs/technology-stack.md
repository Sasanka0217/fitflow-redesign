# FitFlow Technology Stack

## Frontend

**Flutter**

Flutter was selected because it supports iOS, Android, and Web from a single codebase. It also provides good development speed and code reusability for the FitFlow application.

## Backend

**NestJS**

NestJS was selected as the main backend framework. It provides a structured architecture for developing REST APIs and supports the different backend services required by FitFlow.

## AI Microservice

**FastAPI**

FastAPI is used as a separate AI microservice for AI/ML processing and personalized workout recommendations.

## Database

**PostgreSQL**

PostgreSQL is selected as the primary database for storing FitFlow application data.

## Caching and Real-Time

**Redis**

Redis is used for caching and supporting real-time communication requirements.

## Authentication

**AWS Cognito**

AWS Cognito is selected for user authentication and authorization.

## Selected Stack

| Component | Selected Technology |
|---|---|
| Frontend | Flutter |
| Backend | NestJS |
| AI Microservice | FastAPI |
| Database | PostgreSQL |
| Caching / Real-Time | Redis |
| Authentication | AWS Cognito |
